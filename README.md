# **App Name**: MediVault

## Core Features:

- Patient Record Creation: Patient data entry form for recording medical history and visit details.
- Unique Visit ID: Unique ID generation for each patient visit.
- Patient Portal: Patient view for accessing medical records.
- Doctor Interface: Doctor interface for updating patient records and prescribing medications.
- Doctor Management: Admin panel for doctor verification, activation/deactivation, and license-based unique ID management.
- Visit Summary Generation: AI-powered tool that will summarize past records and treatments in preparation for the doctor's patient interaction.
- Secure Data Storage: Secure data storage using Digilocker-like architecture.

## Style Guidelines:

- Primary color: Sky blue (#87CEEB), a calming hue for a healthcare application.
- Background color: Light gray (#F0F8FF), providing a clean and neutral backdrop.
- Accent color: Soft green (#98FF98) for positive interactions.
- Body and headline font: 'Inter', a sans-serif font for a modern, objective feel.
- Use health-related icons to improve findability.
- Subtle transitions to smooth UI changes and provide feedback on interactions.
- Clean, structured layout with a focus on easy data entry and readability.
