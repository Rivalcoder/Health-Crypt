# 🩺 **MediVault** – The Future of Health Records

![MediVault Logo](https://img.icons8.com/ios-filled/50/87CEEB/stethoscope.png)  
*A secure, AI-powered platform for managing digital health records for patients, doctors, and administrators.*

---

## 🚀 Features

- 🧠 **AI-Powered Insights**: Generate patient summaries and identify health trends to support clinical decisions.
- 🔒 **Secure by Design**: State-of-the-art encryption and privacy controls protect your health data.
- 👨‍⚕️ **Doctor Interface**: Update patient records, prescribe medications, and review visit histories.
- 🧑‍💼 **Admin Panel**: Oversee hospital operations, manage doctors, verify applicants, and ensure compliance.
- 🧑‍💻 **Patient Portal**: Access your complete medical history, prescriptions, and visit summaries.
- 🆔 **Unique Visit IDs**: Every patient visit is tracked with a unique identifier.
- 📝 **AI Visit Summary Generation**: Summarize past records and treatments before each consultation.
- 🗂️ **Centralized Health Records**: All your medical data in one place for easy access.
- 📅 **Unified Dashboards**: Manage patient records, doctor schedules, and admin tasks from a single interface.
- 📈 **Health Risk Analysis**: AI analyzes health patterns to identify potential risks early.
- 💊 **Medication Reminders**: Smart reminders ensure you never miss important medications.
- 🏥 **Doctor Management**: Admins can verify, activate/deactivate, and manage doctors by license.
- 🗝️ **Secure Data Storage**: Digilocker-like architecture for robust, compliant storage.

## 👥 User Roles

- **Patient**:  
  - View medical history, prescriptions, and visit summaries.
  - Receive AI-powered health insights and reminders.

## 🚦 Getting Started

### 1. **Clone the Repository**
```bash
git clone https://github.com/yourusername/medivault.git
cd medivault
```

### 2. **Install Dependencies**
```bash
npm install
```

### 3. **Set Up Environment Variables**
- Copy `.env.example` to `.env` and fill in your MongoDB URI and any other required secrets.

### 4. **Run the Development Server**
```bash
npm run dev
```
Visit [http://localhost:3000](http://localhost:3000) to view the app.

### 5. **Database Seeding (Optional)**
- Use the scripts in `Test_Calls/seed.js` and `Test_Calls/migration.js` to seed or migrate your database for demo/testing.
